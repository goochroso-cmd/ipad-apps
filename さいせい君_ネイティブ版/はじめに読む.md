# ★★ 5. 作り方の方針

1. **`AVAudioPlayer` を9個並べた、いちばん単純な形から作る。** まず音が出ることだけ確認
2. **転送の仕組みは `opendisplay` の起動ツールを複製して流用。** 実績のあるものを使う
3. **合格表を先に作る**（4章）
4. 画面は **9ボタン×3ページ**（6章）
5. **Web版（HTML1枚）は触らない。保険として温存する**（`さいせい君_作業場`）

## 音の実装対応表

`AVAudioPlayer` は **iOS 2.2 からある古い標準部品**。iOS 15 で完全に動く。

| 要件 | 使うもの |
|---|---|
| 音量 | `player.volume` |
| パン | `player.pan` |
| **正確な頭出し（息継ぎ解決）** | **`player.currentTime`** |
| **フェードイン/アウト** | **`player.setVolume(_:fadeDuration:)`** |
| 遅延再生 | `player.play(atTime:)` |
| 長い曲 | **ストリーミング再生。何もしなくていい** |

**`AVAudioPlayer` で足りなければ `AVAudioEngine` がある。Web と違って逃げ道が残っている。**

**Air 2 は GarageBand が動いた機械。9個同時再生は余裕。**

## 【済んだ話】v.in02「ブツ消し」── 方針転換で飛ばした

### 原因（推測ではない。コードを読んで特定した）

**`stop()` は、音の波の途中でハサミを入れる。**
波が高い位置にいるときに切ると、そこから一気にゼロへ落ちる。
**この「垂直な段差」がスピーカーには衝撃として伝わる。それが「ブツ」。**

レコードの針を、演奏中に指で押さえて止めた音と同じ。
**曲のせいでも iPad のせいでもない。止め方のせい。**

### 直したこと（`1_本体/iOS/PadBank.swift` の1箇所）

**`stop()` の直前に、40ミリ秒だけかけて音量をゼロへ落とす。**
段差が坂になるので、衝撃が消える。40ミリ秒は**まばたきの10分の1**、人には「すぐ止まった」としか聞こえない。

- **ボタンで止めるとき**と**「ぜんぶ止める」**の両方に入れた（原因は同じ `stop()` 1箇所）
- 坂を下っている40ミリ秒の間にもう一度押されても取り違えないよう、**停止予約に通し番号**を付けた
- 坂で下げた音量は、止めたあと必ず `1.0` に戻す

> **★ これは「曲ごとのフェードアウト設定」（合格表 4-2）とは別物。**
